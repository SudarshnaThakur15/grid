# 🟩 Grid Click Sequence

![React](https://img.shields.io/badge/React-20232A?style=flat&logo=react&logoColor=61DAFB)
![Tailwind](https://img.shields.io/badge/Tailwind_CSS-06B6D4?style=flat&logo=tailwindcss&logoColor=white)

A small React exercise in state updates and timed animations.

## How It Works

1. A 3×3 grid starts out pink.
2. Click any cells and they turn **green**. The app remembers the order you clicked them in.
3. Click the **last cell** (bottom right) and the cells you clicked turn **orange one by one** in that same order, every 500 ms. Then the whole grid turns orange.

## Run Locally

```bash
cd "Grid project"
npm install
npm run dev
```
